# Le dépôt des modèles 3D (Meshy, Tripo…)

Le dossier où tu déposes les modèles faits avec une IA 3D, pour que le Claude du cloud les récupère et les range dans le projet : catalogue, maquette, squelette, animations, couleurs.

## Déposer un modèle (gratuit, depuis le navigateur)

1. Ouvre la page de ce dossier sur GitHub : https://github.com/madhiphares-eng/mon-projet/tree/echos-ether/depot-modeles
2. Clique sur **Add file**, puis **Upload files**.
3. Glisse ton fichier `.glb` (25 Mo au plus par fichier dans le navigateur).
   - **Nomme-le** comme dans les prompts : `androide-empire.glb`, `pirate-abordage.glb`, `detenu-corvee.glb`…
   - Ajoute dans le nom l'outil utilisé : `androide-empire.meshy.glb` ou `androide-empire.tripo.glb`.
4. En bas, garde **Commit directly to the echos-ether branch**, puis clique sur **Commit changes**.
5. Dis au Claude du cloud : « j'ai déposé des modèles ».

## Avant d'exporter

- **Le format** : GLB.
- **Le poids** : moins de 25 Mo. Si le fichier est trop lourd, réduis la texture (2K plutôt que 4K) ou le nombre de faces à l'export, si l'outil le propose.
- **La licence** :
  - **Meshy gratuit** : CC BY 4.0, un jeu vendu est permis, en créditant Meshy.
  - **Tripo gratuit** : l'usage commercial demande un abonnement. Un modèle Tripo fait en gratuit peut servir de maquette ou de référence, mais pas dans le jeu vendu.
